# Hi, I'm Martin Marañon

**Computational Science & Engineering at ETH Zurich · AI, scientific computing and practical software**

I'm interested in building AI tools that help people make decisions and get work done, especially in operations and logistics. My work spans hackathon prototypes, data integration and an ongoing team project on efficient machine-learning training.

## Selected projects

### [Resilix — Agentic Disaster Awareness](https://github.com/martinmaranon2/resilix)
A team hackathon project combining hazard information, maps and conversational AI for disaster awareness and preparedness.

**My contribution:** the Swiss data-integration workstream, including provider clients, data models and agent tools. This repository brings together the team's final web application and the original development workstreams.

*Python · TypeScript · Next.js · React · Bun*

### [UBS Client Advisor — DialogueIQ](https://github.com/martinmaranon2/ubs-client-advisor)
A shared Zurich hackathon prototype for financial advisors: client profiles, conversation analysis, chat and voice assistance. The repository contains the primary advisor app and the earlier dashboard versions, with the team's original history preserved.

*TypeScript · Next.js · React · Supabase · PostgreSQL · OpenAI*

### [WeatherGenerator — Memory-Efficient Training](https://github.com/martinmaranon2/WeatherGenerator)
**Ongoing ETH DPHPC team project.** We are profiling and improving memory efficiency in the training data pipeline of ECMWF's WeatherGenerator, from data loading and CPU memory through GPU inputs.

My fork makes our shared research setup and experiment records easy to explore. The underlying model and framework come from the upstream WeatherGenerator collaboration.

*Python · PyTorch · HPC · Performance profiling*
